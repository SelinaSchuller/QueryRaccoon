High impact / most expected in a DB GUI:
SQL syntax highlighting — swap the plain textarea for CodeMirror or Monaco. Makes the editor actually feel like a tool.
Export results — "Copy as CSV", "Copy as JSON" buttons on the results pane. Simple but very useful.
Table structure tab — clicking a table shows column names, types, nullability, indexes instead of just running a SELECT.
Security (already planned):
4. Password encryption — the AES-256 keyfile approach we noted down. Right now passwords sit in plaintext in the config dir.
Nice-to-have:
5. Query history — persist recent queries per connection so you can re-run them.
I'd suggest doing syntax highlighting next — it's the biggest UX jump and makes the app feel complete. CodeMirror 6 has a clean JS API and works well in Svelte. After that, export is quick and table structure is a natural companion to the schema browser.


Production:
Encrypt passwords in connections.json using only the Go standard library (crypto/aes, crypto/cipher, crypto/rand). On first run, generate a random AES-256 key and store it in ~/.config/QueryRaccoon/.keyfile with restricted permissions. Encrypt passwords with that key before saving, decrypt on load. Change is fully contained in internal/storage/storage.go — nothing else needs to touch it.
